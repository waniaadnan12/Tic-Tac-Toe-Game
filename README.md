A simple Tic Tac Toe game built with Python.
Two players take turns playing as X and O on a 3×3 board.

📌 Features
Two-player gameplay

Player X goes first

Input validation for positions 1-9

Prevents players from choosing an occupied position

Detects winning combinations

Detects draws

Displays the board after every move

🛠️ Requirements
Python 3.x

No external libraries are required.
